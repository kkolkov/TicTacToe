Задание

Создайте консольную игру «Крестики-нолики», позволяющую двум игрокам играть друг против друга, поочередно размещая свои метки на сетке 3x3.
Требования:

Структура игры:
Игра должна проходить на сетке 3x3.
Два игрока должны иметь возможность играть, поочередно размещая свои метки (X и O) на сетке.
Игра должна определять, когда один из игроков выиграл, или, что игра закончилась вничью.
Соблюдение принципов объектно-ориентированного проектирования:
Наследование:
Создайте базовый класс Player, содержащий общие атрибуты и методы для игрока.
Создайте два класса HumanPlayer и AIPlayer, наследующие от класса Player. Для этой задачи можно сосредоточиться на HumanPlayer, но подумайте, как можно реализовать AIPlayer в будущем.
Композиция:

Используйте композицию для управления игровым полем. Создайте класс Board, содержащий двумерный массив для представления сетки.
Класс Game должен содержать экземпляры объектов Board и Player для управления состоянием игры и взаимодействием игроков.
Описание классов:
класс Player:
атрибуты: name, mark (либо X, либо O);
методы: makeMove(), который будет переопределен в производных классах;
класс HumanPlayer:

yаследуется от Player;
переопределяет makeMove(), чтобы позволить игроку вводить свой ход;
класс Board:

атрибуты: двумерный массив grid для представления поля;
методы: displayBoard(), isFull(), checkWin(), placeMark(int row, int col, char mark);
класс Game:

атрибуты: Board board, Player player1, Player player2, currentPlayer;
методы: startGame(), switchPlayer(), checkForWinOrDraw().
Ход игры:
Инициализируйте игру с двумя объектами HumanPlayer и объектом Board.
Поочередно предоставляйте ходы двум игрокам, позволяя им размещать свои метки на поле.
После каждого хода проверяйте, выиграна ли игра или закончилась вничью.
Объявите результат и завершите игру, когда будет достигнуто условие победы или ничьей.
Дополнительные возможности* (выполнение по желанию):
реализуйте простую AI для класса AIPlayer, которая делает случайные допустимые ходы;
добавьте проверку ввода, чтобы убедиться, что игроки вводят допустимые ходы;
улучшите пользовательский интерфейс для лучшего взаимодействия с пользователем.

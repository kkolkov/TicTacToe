# Крестики-нолики

Консольная игра на Java: поле 3×3, игроки ходят по очереди, побеждает первый,
собравший три своих знака в строке, столбце или диагонали.

## Компиляция и запуск

Нужен JDK 8 или новее. Выполните в папке проекта:

```sh
javac -encoding UTF-8 -d out *.java
java -cp out Main
```

По умолчанию играют два человека. Для хода введите строку и столбец от 1 до 3
через пробел, например `1 2`. При ошибке программа попросит повторить ввод.

Типы игроков можно передать аргументами: первый играет за X, второй — за O.

- `human` — человек.
- `ai` — бот со случайными ходами.
- `simple` — бот, выбирающий первую свободную клетку по строкам.

```sh
java -cp out Main human ai
java -cp out Main human simple
java -cp out Main simple ai
```

## Использованные паттерны

- **Singleton:** конструктор `Game` закрыт. `Game.getInstance(board, player1, player2)`
  создаёт игру только при первом вызове. Следующие вызовы возвращают тот же объект,
  новые аргументы не меняют его зависимости.
- **Factory:** `PlayerFactory.createPlayer(...)` создаёт игрока по строковому типу.
  Дополнительная возможность — поддержка третьего типа `SimpleAIPlayer`.
- **Builder:** `new Board.Builder().build()` создаёт готовое пустое поле.
  Конструктор `Board` закрыт. Пока используется стандартное поле 3×3 без дополнительных настроек.
- **Dependency Injection:** поле и игроки создаются в `Main` и передаются
  в закрытый конструктор `Game` через `getInstance`. Игроки получают поле,
  а `HumanPlayer` также получает `Scanner` через конструктор. Spring не требуется.
